# EV Population Supervised ML Research Question Notebooks

These seven Kaggle-ready notebooks correspond to seven research questions for the Electric Vehicle Population Data project.

## How to use on Kaggle

1. Create a new Kaggle notebook.
2. Attach the dataset: https://www.kaggle.com/datasets/rajkumarpandey02/electric-vehicle-population-data
3. Upload or copy one of these `.ipynb` files into Kaggle.
4. Run all cells.
5. The table CSV and figure PDF will be saved in `/kaggle/working`.

Each notebook has an optional `DATASET_PATH` variable. Leave it as `None` for automatic discovery, or set it manually if needed.
